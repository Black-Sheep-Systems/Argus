    Restart the Server

    Everything on the server goes offline for about two minutes: websites, mail and Hephaestus. Argus disconnects and you sign in again afterwards.

    Roll Back

    Puts an earlier version of the app live. The database is left as it is: columns added by newer versions stay, which does no harm. What is live now is kept, so a rollback can itself be undone. Server checks run afterwards.

      Blocked Addresses

      Blocked addresses can't reach anything on the server: SSH, mail, websites. The block is applied before anything else sees the traffic and is restored at every start. Your own addresses and this server can't be blocked. An address where a mailbox or upload account has signed in can be, after you confirm.

      Addresses

      Every one of these was refused. SSH needs your key and your code; mail failures are wrong passwords. Your own addresses (where you sign in over SSH as mattridge or root, and any listed in /etc/argus/own-addresses on the server) are left out. Used Your SSH Key means your key was accepted there but the code was never right: if that wasn't you, your key has been copied; replace it and block the address. Addresses where a mailbox or upload account has signed in are only listed if they were also refused, marked Has Signed In: usually a mistyped password, but it could be a stolen one.
